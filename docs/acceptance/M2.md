# M2 验收清单（Chat the Day v1）

> **验收前需要你先做两件事**（只做一次）：
> 1. **执行数据库迁移**：Supabase 控制台 → SQL Editor → 粘贴 `supabase/migrations/002_chat.sql` 的全部内容 → Run。看到 "Success" 即可（可以重复执行，不会出错）
> 2. **配置 DeepSeek 密钥**：Vercel → 项目 soul_matter → Settings → Environment Variables → 添加 `DEEPSEEK_API_KEY`，值是你在 DeepSeek 开放平台创建的 API Key，Environments 勾选 **Production** 和 **Preview**（不要加 `NEXT_PUBLIC_` 前缀）。保存后到 Deployments 里对预览部署点 **Redeploy**，新的变量才会生效
>
> 然后打开 PR 里的预览链接，用测试账号登录，手机和电脑各走一遍。带 🤖 的条目自动化测试已经用"假 AI"检查过流程；**AI 说得好不好只能你来判断**。
