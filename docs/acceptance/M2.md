# M2 验收清单（Chat the Day v1）

> **验收前需要你先做两件事**（只做一次）：
> 1. **执行数据库迁移**：Supabase 控制台 → SQL Editor → 粘贴 `supabase/migrations/002_chat.sql` 的全部内容 → Run。看到 "Success" 即可（可以重复执行，不会出错）
> 2. **配置 AI 服务（以硅基流动为例）**：Vercel → 项目 soul_matter → Settings → Environment Variables，添加下面三个变量，Environments 都勾选 **Production** 和 **Preview**（都不要加 `NEXT_PUBLIC_` 前缀）：
>    - `AI_API_KEY` = 你在硅基流动「API 密钥」页面创建的密钥
>    - `AI_BASE_URL` = `https://api.siliconflow.cn/v1`
>    - `AI_MODEL` = 在硅基流动「模型广场」里复制的模型名，例如 DeepSeek-V3 对应的那一串（形如 `deepseek-ai/...`）
>
>    保存后到 Deployments 里对预览部署点 **Redeploy**，新的变量才会生效。以后想换模型，只要改 `AI_MODEL` 再 Redeploy
>
> 然后打开 PR 里的预览链接，用测试账号登录，手机和电脑各走一遍。带 🤖 的条目自动化测试已经用"假 AI"检查过流程；**AI 说得好不好只能你来判断**。
