# prompts · AI 的"说明书"

这个文件夹里都是纯文字，**你可以直接编辑**（在 GitHub 网页上点文件 → 右上角铅笔图标），这是你参与 AI 质量最直接的方式。

| 文件 | 作用 |
|---|---|
| `chat-guide.md` | Chat the Day 里 AI 的人设和规则（system prompt） |
| `test-scripts.md` | 测试剧本：每次改规则后，扮演用户跑一遍 |
| `rubric.md` | 评分表和评分记录 |

修改流程：改 `chat-guide.md` → 第一行 version 加 1 → 在预览链接上跑剧本 → 在 `rubric.md` 记分 → 分数不降才合并上线。
